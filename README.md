# Masterthesis_unibe

This repository contains empirical data from the Master's thesis:

**_Rotational Invariance in Deep Neural Networks: Analyzing the Robustness to Unseen Viewpoints of Learned Objects_**

## Contents

- Empirical data used in the thesis
- R and Python scripts used for data analysis (in the `Auswertung` folder)

## Important Notes

- **Code is not plug-and-play**: To run the deep neural network models, you will need to adjust the directory structure according to your local setup.
- All data in the `Auswertung` folder is provided along with the R or Python script used to analyze it for the thesis.

## Author

This work was completed as part of a Master's thesis at the University of Bern (UniBE).
